## Artwork credits

- **Pokémon species icons:** Original-151 Generation VII 40x30 icons from
  [PokeAPI Sprites](https://github.com/PokeAPI/sprites), revision
  `4bc9d60186fe2e499ee2f3d4d1b796806cb99a67`. The X3 package contains
  one-bit adaptations and larger presentation variants derived from them.
- **Evolution-stone icons:** Moon, Fire, Thunder, Water, and Leaf Stone images
  from [PokéSprite](https://github.com/msikma/pokesprite), revision
  `c5aaa610ff2acdf7fd8e2dccd181bca8be9fcb3e`. The X3 package contains
  one-bit adaptations in two display sizes. The Link Cable has no icon.
- **Pokédex layout and X3 renders:**
  [dmellok / u/xDaftTurtle](https://github.com/dmellok), shared in the
  [original Reddit post](https://www.reddit.com/r/XTEINK/comments/1ve0pr4/comment/p1lpy0w/?context=3).
  The cards were created with [Tesserae](https://github.com/dmellok/tesserae)
  using PokéAPI data and sprites, then adapted to the portrait and landscape
  one-bit formats used by this firmware.

PokeAPI Sprites states that its repository uses CC0 while separately stating
that all image contents are copyright The Pokémon Company and that it does not
clear third-party rights. PokéSprite states that its sprite images are
copyright Nintendo/Creatures Inc./GAME FREAK Inc.; its MIT licence applies to
its code and non-art materials. The Pokédex creator publicly shared downloadable
X3 renders but did not attach an explicit redistribution licence.

## Removal or credit correction

A request should identify the affected file, artwork family, source, or credit
and the requested action. When a credible request is received, the maintainer
will remove the affected release asset while it is reviewed, then replace the
artwork or correct the credit and publish new checksums.

GitHub also maintains its own
[copyright claim process](https://docs.github.com/en/site-policy/content-removal-policies/submitting-content-removal-requests).
