Recommended

Full install

  1. Download the full-install ZIP to a computer.
  2. Open or extract the ZIP. Do not copy the ZIP file itself to the SD card.
  3. Power off the X3 and put its SD card in the computer.
  4. Back up any /.crosspoint/pokemon*.bin files if present. Earlier pokemon-v2-a.bin and pokemon-v2-b.bin saves migrate automatically.
  5. Copy update.bin to the SD-card root and merge the extracted pokemon folder into the root.
  6. Do not format the SD card. Do not delete any existing folder. Do not replace any existing folder. Your books, sleep covers, settings, reading progress, and Pokémon saves must stay in place.
  7. Confirm update.bin and pokemon are directly at the SD-card root, safely eject the card, and return it to the X3.
  8. Open Settings → System → SD Card Firmware Update, select update.bin, and confirm.

The package does not contain or replace Pokémon saves, books, or reading data. If your artwork is still under /.crosspoint/pokemon/, use this full install once to move to the visible folder.

Updates after the full install

Firmware-only Wi-Fi update

  1. Use this route only if /pokemon/ is already installed at the SD-card root.
  2. Download Firmware only.
  3. Leave the SD card inside the X3 and open File Transfer.
  4. Open the address shown by the X3 and upload the downloaded .bin file to the SD-card root.
  5. Exit File Transfer, open Settings → System → SD Card Firmware Update, select the file, and confirm.

Back up the SD card first. Do not install this build on an X4, X4 Pro, Sticky, or another device.
